GITHUB-ACTIONS-BUILD.yml

مهم:
- النسخة التنفيذية موجودة في المسار:
  .github/workflows/build.yml
- يجب إبقاء النسخة التنفيذية داخل هذا المسار بالضبط حتى يتعرف GitHub Actions عليها.
- لا تنقل النسخة التنفيذية إلى المجلد الرئيسي؛ نسخة المجلد الرئيسي للعرض والنسخ فقط.

لرفع المشروع:
1) ارفع جميع محتويات هذا المجلد إلى المستودع في GitHub.
2) تأكد من ظهور .github/workflows/build.yml في المستودع.
3) افتح Actions ثم اختر Build AflatoonMubdi dylib.
4) شغّل Run workflow.
